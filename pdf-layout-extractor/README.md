# Layout-preserving PDF → text extractor (with bold/italic tags)

> **Sample / demo project.** The input PDF is a synthetic document generated by `make_sample_pdf.py`; all numbers in it are invented.

Turns a PDF with live (selectable) text into a plain-text file that keeps the page flow:

- **Page structure** – every page starts with `===== Page N / M =====`.
- **Line wraps & paragraph breaks** – lines break exactly where they break in the PDF; larger vertical gaps become blank lines.
- **Indentation, tables, columns** – each text span is placed on a fixed-width character grid from its x-coordinate, so table cells and indents line up.
- **Emphasis** – bold/italic detected from both font flags and font names (`Helvetica-BoldOblique`, `Arial-BoldItalicMT`, …):
  - `--style markdown` (default): `**bold**`, `*italic*`, `***bold italic***`
  - `--style html`: `<b>bold</b>`, `<i>italic</i>`, `<b><i>bold italic</i></b>`

## Usage
```bash
pip install pymupdf
python extract_layout.py input.pdf output.txt                 # Markdown-style tags
python extract_layout.py input.pdf output.txt --style html    # HTML tags
python extract_layout.py input.pdf output.txt --cols 140      # wider grid for landscape pages
```

## Notes / limits
- Needs live text; scanned pages would need OCR first (e.g. Tesseract) – not included here.
- Emphasis tags add characters, so a bold table header can sit a few characters wider than plain rows; the *start* of every cell is snapped to the grid.
- Fonts that fake bold by stroking (no "Bold" in the name, no flag) cannot be detected from text metadata alone.
