# Transaction auto-categorization (Google Sheets / Excel)

> **Sample / demo workbook.** All 60 transactions are synthetic, generated by `build_workbook.py`. No real client or bank data.

File: [`transaction_categorizer_SAMPLE.xlsx`](transaction_categorizer_SAMPLE.xlsx) – open in Google Sheets (File → Import) or Excel.

| Sheet | What it does |
|---|---|
| **Transactions** | Paste raw rows into A–C (Date, Description, Amount). Columns D–G tag themselves: Category, Income/Expense, matched keyword, and a `⚠ Review` flag. Formulas are pre-filled for 1,000 rows, so new rows are tagged with no copying. |
| **Rules** | The rulebook: `keyword → category → expected group`. Add a row to add a rule – no formula edits. |
| **Summary** | SUMIFS/COUNTIFS totals per category, total income/expense, and number of rows needing review. |

## The core formula (keyword found *anywhere* in the description)
```
=IF($B2="","",IFERROR(
   LOOKUP(2^15, SEARCH(Rules!$A$2:$A$200&"",$B2)/(Rules!$A$2:$A$200<>""), Rules!$B$2:$B$200),
 "Uncategorized"))
```
- `SEARCH` is case-insensitive and acts as a "contains" (wildcard `*keyword*`) match against every rule at once.
- Dividing by `(keyword<>"")` makes blank rule rows errors, so they are skipped.
- `LOOKUP(2^15, …)` returns the **last** matching rule → put broad keywords (`UPI`, `NEFT`) at the top and specific ones (`SWIGGY`, `SALARY`, `REFUND`) lower down. Example: `UPI REFUND FLIPKART` → **Refunds**, not Shopping.
- Works natively in both Google Sheets and Excel – no `ARRAYFORMULA`, no Ctrl+Shift+Enter.

### Google Sheets one-formula-per-column alternative
If you prefer a single formula at the top of a column (auto-extends to every row):
```
=MAP(B2:B, LAMBDA(d, IF(d="",,IFERROR(
   LOOKUP(2^15, SEARCH(Rules!A2:A200&"",d)/(Rules!A2:A200<>""), Rules!B2:B200),"Uncategorized"))))
```
For exact codes (e.g. merchant IDs) use `XLOOKUP(code, Rules!A:A, Rules!B:B, "Uncategorized")`, and for wildcard patterns stored in the rulebook (`*SWIGGY*`) use `XLOOKUP(B2, Rules!A:A, Rules!B:B, , 2)` (match mode 2 = wildcard).

## Result on the sample data
57 of 60 rows are tagged automatically; the 3 cheque deposits (`CHQ DEP …`) have no rule and are flagged `⚠ Review` – adding a `CHQ DEP` rule fixes them instantly.

## Caveats
Short keywords can over-match (`OLA` also matches `COLA`). Use a more specific keyword (`OLA CABS`) or add a space/delimiter (`/OLA`) in that case.
